NeatPlan - Full App Audit

Scope: mobile viewports (6 devices x 16 pages = 96 combos), desktop page walk, SEO/Lighthouse, backend concurrency (static review + live load bursts), UI consistency, competitor feature-gap research. Method: independent agents across three vendors (Codex, Cursor, Gemini) plus Claude; every substantive finding adversarially verified by a different vendor than its author. Verdicts: 35/37 confirmed, 2 uncertain (dev-server Lighthouse artifacts), 0 refuted.

Run timeline: audit ran 2026-07-11 22:43-23:35 UTC (session terminated mid-wave-2; desktop walk partially complete - 4 salvaged findings), resumed and synthesized 07:37-08:00 UTC.

Summary

1critical18high 30medium17low 14feature gaps

The backend core is solid: task completion is transactional with optimistic locking, the cron scheduler is protected against double-fire, admin endpoints paginate, and the app survived every concurrent burst (50 parallel logins, 100 parallel reads, 20-way double-completion of the same task) without data corruption. The problems cluster in four places: (1) a critical mobile layout bug that clips dashboard content on every phone, (2) the admin/cleaner UIs are two different design systems with duplicated logic, (3) SEO/PWA basics are absent (one shared title for every route, no robots/sitemap/apple-touch-icon, base URL hardcoded to the wrong port), and (4) several check-then-act races that surface as 500s instead of 409s under concurrency.

  10. P2 - Move state mutations out of GET /api/room-schedules.

low POST /api/rooms returns 500 instead of 409 on concurrent unique-name conflict verified
backend-concurrency: /api/rooms POST
evidence + fix

20 parallel POST /api/rooms with identical name -> 1x200 + 19x500 (not 19x409). DB confirms correctness (rooms.name is @unique in prisma/schema.prisma:55, only 1 row created, verified via psql count). But the Prisma P2002 unique-constraint error from src/app/api/rooms/route.ts:59 (prisma.room.create) is not caught explicitly, falls through to the generic catch (lines 69-81), and returns HTTP 500 {"error":"Something went wrong"}. Confirmed via /tmp/neatplan-dev.log stack traces: 'Unique constraint failed on the fields: (`name`)' code P2002, each followed by 'POST /api/rooms 500'.

Catch PrismaClientKnownRequestError with code P2002 in the POST handler and return 409 Conflict with a clear message, matching the pattern already used correctly in src/app/api/cleaner/rooms/[roomId]/complete/route.ts (optimistic-concurrency 409). Low severity: no data integrity issue, just wrong HTTP semantics and noisy error logs.

Add min-w-0 to the flex-1 content column in conditional-layout.tsx:29 so its own overflow-x-auto descendants (e.g. the Users table wrapper) can do their job instead of blowing out the whole page.

medium Sidebar navigation gives zero loading feedback; a nav click can be silently dropped if the user clicks elsewhere before the route resolves

evidence + fix

Repro script clicked sidebar links Dashboard->Rooms->Equipment->Schedule->Audit Log in quick succession (500ms settle + networkidle wait between each). Feature gaps vs competitors (author: Gemini - market research, ranked by value)

Top themes: audit-proof verification (QR/NFC room check-in, photo evidence), offline-first resilience for poor care-home Wi-Fi, objective cleanliness measurement (ATP integration), and one-click CQC evidence packs.

high value NFC/QR Code Room Check-ins (Location-Verified Cleaning)
detail

Competitors AssureWorks, SmartTask, Radar Healthcare offer location-verified check-ins via QR/NFC tags. CQC inspectors frequently identify pencil-whipping (falsifying records). Scanning a physical tag inside the room provides indisputable proof of presence, directly addressing CQC Safe KLOE on Infection Control.

Implement QR/NFC scanner in mobile app (small effort: standard barcode plugin). Print tags for each room. Eliminates most critical audit vulnerability. High commercial value; care homes will pay premium for absolute certainty during CQC inspections.

high value Photographic Evidence / Image Capture at Task Completion
detail

SafetyHub, QCS, ZenMed all embed image capture in completion logs. Protects against negligence claims and provides immediate visual proof of deep-cleaning standards post-outbreak, especially critical for isolation rooms. Now expected in care home compliance audits.

Add camera permissions and image compression to mobile app; store images in S3 attached to completion logs (small-medium effort). High commercial value and regulatory validation. Direct mitigation of liability claims.

high value Offline-First Mobile Mode with Sync Queue
detail

Radar Healthcare, SmartTask provide offline mode. UK care homes have notoriously poor Wi-Fi coverage on residential floors. Staff cannot clock tasks if connection drops mid-shift, creating audit gaps and user frustration. Represents operational risk.

Implement service worker caching and IndexedDB queue for task completions (medium effort). Queue actions for sync when network returns. High commercial value for any care home with unreliable connectivity (majority of UK market).

high value ATP (Adenosine Triphosphate) Testing Integration
detail

Competitors QCS, Infection Prevention Connect, SmartTask integrate with ATP meters (Hygiena, 3M). ATP swabs provide objective proof of microbial contamination levels. Direct evidence for CQC inspectors and infection control teams. NHS infection prevention guidance increasingly mandates ATP validation.

API integration with ATP meter manufacturers (medium effort). Allow staff to log ATP readings directly in app, flagging fail thresholds. Add dashboard heatmaps of highest-risk areas. High commercial value; objective measurement replaces subjective task completion and becomes gold-standard audit evidence.

high value Staff Competency & Training Records Audit Trail
detail

QCS, Radar Healthcare, RLDatix all track staff training compliance. CQC Safe KLOE explicitly requires proof that cleaning staff have received infection control training and competency assessments. Currently NeatPlan has no training module or competency tracking.

Add Staff Training module: track mandatory training dates, record competency sign-offs, flag overdue refreshers (medium effort). Link training status to task assignment eligibility. High commercial value; directly addresses CQC inspection question on staff training records.

high value Audit Report Export & CQC Evidence Packs
detail

QCS, Radar Healthcare, RLDatix generate branded compliance reports and pre-formatted CQC evidence packs in seconds. Care home managers currently must manually collate data for inspectors. Audit readiness is a major sales driver.

Build templated audit report generator: select date range, room/department, include completion logs, photos, ATP results, training records, incident logs (medium effort). Export as PDF with care home branding. High commercial value; makes audit preparation 80-90% faster, positioning NeatPlan as audit-ready infrastructure.

medium Consumables & Stock Level Management
detail

Healthcheck360, CleanTelligent track PPE and disinfectant stock. Running out of gloves, aprons, or specific disinfectants compromises infection control protocol compliance. Creates operational risk and audit findings.

Add inventory module: track par levels for consumables (PPE, disinfectants, mop heads), allow cleaners to request stock via app, alert managers when levels drop below threshold (medium effort). Medium commercial value; improves budget control and prevents operational halts.

medium UV-C / UVC Equipment Disinfection Scheduling & Validation
detail

ZenMed, Infection Prevention Connect, SmartTask support UV-C equipment scheduling. Many modern care homes now deploy UV-C trolleys for terminal disinfection of high-risk areas. Lack of scheduling integration creates gaps in usage logging.

Add UV-C equipment as a distinct schedule type with run-time logging (small-medium effort). Track exposure duration, areas treated, maintenance cycles. Medium commercial value; enables care homes to demonstrate terminal disinfection compliance.

medium Outbreak Mode with Enhanced Protocols
detail

QCS, Radar Healthcare, Infection Prevention Connect all offer outbreak mode that auto-triggers heightened cleaning frequencies, enhanced PPE requirements, and staff isolation protocols. COVID-era lesson: care homes need rapid protocol escalation.

Add outbreak management mode: when activated, flag isolation rooms, auto-escalate cleaning frequencies, require photo evidence, enforce enhanced PPE logging (medium effort). Integrates with training records and inventory alerts. Medium commercial value; dramatically improves response speed during infection outbreaks.

medium Room Risk Categorization & Dynamic Schedule Weighting
detail

QCS, Radar Healthcare assign risk ratings to rooms (isolation, high-touch, immunocompromised units). Cleaning frequency and disinfectant type should vary by risk. NeatPlan currently treats all rooms equally.

Add room risk tiers (isolation, high-touch areas, standard) with linked disinfectant requirements and escalated frequencies for high-risk (small-medium effort). Display on cleaner dashboard with visual flags. Medium commercial value; ensures resources are allocated proportionally to actual risk.

medium COSHH (Control of Substances Hazardous to Health) Compliance Logging
detail

AssureWorks, SafetyHub require COSHH data sheets linked to each cleaning task. UK law (Health and Safety at Work Act) mandates COSHH assessments for all hazardous substances. NeatPlan does not track chemical usage or exposure data.

Add COSHH module: upload Safety Data Sheets per disinfectant, log chemical usage per room, track exposure incidents (medium effort). Integrates with consumables tracking. Medium commercial value; closes legal compliance gap and protects against HSE enforcement actions.

medium Multilingual Cleaner Interface
detail

Radar Healthcare, SmartTask offer multilingual UIs. Significant UK care home housekeeping workforce are non-native English speakers. Low task completion and user frustration stem from language barriers.

Implement i18n on cleaner-facing pages (small-medium effort). Prioritize Polish, Romanian, Portuguese (largest care home cleaner populations in UK). Medium commercial value; dramatically improves user adoption and reduces training overhead.

low Voice-to-Text Task Completion Notes
detail

ZenMed offers voice dictation for task notes. Cleaners wearing gloves do not enjoy typing on touchscreens. Voice input improves note quality and speed.

Add native OS voice dictation API to note fields (small effort: leverage browser SpeechRecognition API or native OS capabilities). Low-medium commercial value; highly appreciated delighter feature that demos well to buyers.

low Infection Risk Heatmapping on Floorplan View
detail

Infection Prevention Connect offers floorplan overlay with missed-cleaning and active-infection heatmaps. Visually striking but underutilized in daily practice compared to list views.

Build custom floorplan uploader and room-position mapping, overlay missed-task and ATP-failure heatmaps (large effort). Low commercial value for MVP; useful for enterprise sales demos but not core to daily workflow.
