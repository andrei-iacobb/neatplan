QR/NFC Room Check-in - Build Plan

Goal: location-verified cleaning. Each room gets a printable QR label (primary, works on every device) and optionally an NFC sticker carrying the same link. A cleaner scans at the room door; completions record QR / NFC / MANUAL with a check-in timestamp - proof-of-presence evidence for CQC.
Method: architecture by codex, UX analysis by gemini, third-vote review by cursor (27 issues triaged - amendments folded into the queue), synthesis by Claude. Raw inputs: /home/andrei/x/neatplan-audit-loop/qr-feature/. Branch: feature/qr-nfc-checkin.

Architecture decisions

DecisionChoice
TokenStable per-room signed token: base64url({v:1, roomId, tokenVersion}) + "." + HMAC-SHA256 with dedicated LOCATION_TOKEN_SECRET (+ _PREVIOUS rotation window). DB stores only an integer version - a leak exposes no usable tokens. Regenerate = increment Room.locationTokenVersion; old labels die instantly.
Deep link/clean/scan?t=<token>&m=qr|nfc - same signed token on both carriers; m is a hint, never authorization. Works from native camera apps and native NFC tag opening (iOS included); login redirect preserves the full query.
Check-inPOST /api/cleaner/check-ins exchanges token for a single-use 5-minute RoomCheckIn (user + room + version bound, idempotent while valid). Completion consumes it inside the existing transaction; verificationMethod is derived server-side from the consumed row only - the client can never claim QR. No check-in = MANUAL, always allowed in v1, visibly flagged.
Audit copyMethod + check-in time are snapshotted onto the completion log (same pattern as roomName/scheduleTitle) so purging operational check-ins never damages the compliance record.
LabelsClient-side SVG QR (qrcode lib) + A4 print CSS - no PDF infrastructure. Label anatomy per gemini: room name, ≥50mm QR, "Scan to log cleaning", version tag; laminate matte, mount ~1.2m.
NFCSticker holds the same URL as NDEF record. In-browser write/read only on Android Chrome (NDEFReader); iOS opens tags natively. QR-only rollout is first-class - NFC is an optional extra.
LibrariesOnly qrcode + jsqr (lazy fallback when BarcodeDetector is missing, which includes iOS Safari - fallback is first-class). HMAC via node crypto.

Honest threat model

This proves a cleaner held a room-specific link moments before completing - it stops casual sofa-completion, wrong-room mistakes, and fabricated client verification. It does not stop a shared photo of the label or a cloned NFC tag; static carriers cannot. Mitigations: single-use short-lived check-ins, version revocation, token redaction from logs/history, rate-limited exchange, Referrer-Policy: no-referrer. Stronger presence proof (rotating displays, BLE) is a possible v3.

Deferred to v2

  • Offline scan queue (optimistic check-in + background sync) - biggest UX win for patchy Wi-Fi, big surface.
  • Short manual room codes (A8K2-style) with per-shift rate limits + geofence flagging.
  • Scan-failure instrumentation feeding an admin "scan health" panel.
  • Facility policy toggle: require verified check-in for completion.
  • Equipment tag support.
